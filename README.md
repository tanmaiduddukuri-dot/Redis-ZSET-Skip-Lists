This repository contains a case study on the Skip List data structure used by Redis Sorted Sets (ZSETs). The project explores Skip List construction, search operations, insertion algorithms, time complexity analysis, and a comparison with Red-Black Trees. A leaderboard example is used to demonstrate how Redis efficiently supports ranking, range queries, and score-based lookups using probabilistically balanced Skip Lists.

Key Features

Skip List construction with deterministic level promotion
Search path tracing for leaderboard scores
Java implementation of Skip List search and insertion
Complexity analysis (average and worst case)
Comparison with Red-Black Trees
Redis ZSET design rationale and real-world applications

Applications

Redis Sorted Sets (ZSETs)
Gaming leaderboards
Ranking systems
Database indexing
In-memory data stores
Search and recommendation systems
